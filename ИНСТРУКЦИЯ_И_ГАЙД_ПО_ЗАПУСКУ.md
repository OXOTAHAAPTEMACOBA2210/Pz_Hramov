## 1. Подготовка и скачивание проекта на новом компьютере

### Вариант А: Клонирование через Git (в командной строке / PowerShell)
```cmd
git clone https://github.com/OXOTAHAAPTEMACOBA2210/Pz_Hramov.git
cd Pz_Hramov
```

### Вариант Б: Без Git (через браузер)
1. Перейдите по ссылке: [https://github.com/OXOTAHAAPTEMACOBA2210/Pz_Hramov](https://github.com/OXOTAHAAPTEMACOBA2210/Pz_Hramov)
2. Нажмите зелёную кнопку **`Code`** в правом верхнем углу и выберите **`Download ZIP`**.
3. Распакуйте скачанный архив и откройте папку проекта в командной строке.

### Установка библиотек:
```cmd
py -m pip install django python-docx
```
*(Если настроен прямой вызов python, можно `pip install django python-docx`)*

> **Важно:** Базы данных SQLite (`db.sqlite3`) уже входят в репозиторий со всеми заполненными данными — повторно мигрировать ничего не нужно.

## 2. Запуск и демонстрация Проекта №1 — «Университет Хогвартс»

### Команды для запуска:
```cmd
cd hogwarts
py manage.py runserver 8000
```
В браузере откройте: **[http://127.0.0.1:8000/](http://127.0.0.1:8000/)**

### Учетные данные для панели администратора:
* **Адрес админки:** [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)
* **Логин:** `admin`
* **Пароль:** `admin`
*(Также доступен логин `mrspa` с паролем `admin`)*

### Что показывать преподавателю при защите:
1. **Главная страница (`/`):**
   * Баннер `Jumbotron` с приветствием и кнопками быстрого перехода.
   * Информационное сообщение `Alert`.
   * Цветные панели `Panel` со счетчиками (Студенты, Преподаватели, Группы, Факультеты, Дисциплины) — все блоки и кнопки кликабельны и открывают соответствующие списки.
2. **Боковое меню навигации:** оформлено через `list-group`, содержит бейджи `badge` с актуальным числом записей.
3. **Раздел «Студенты» (`/students/`):**
   * Имена выведены в формате **«Фамилия и Имя»** (Грейнджер Гермиона, Поттер Гарри и т.д.) с сортировкой по алфавиту фамилии.
   * В первой колонке выводится сквозная нумерация **#** с учетом пагинации (1..5 на 1-й стр., 6..10 на 2-й стр., 11 на 3-й стр. — номер не сбивается).
   * **Полнотекстовый поиск**: введите в строку поиска фамилию (например, `Поттер`) и нажмите «Найти» — список мгновенно отфильтруется.
   * **Пагинация**: список разбит на страницы по 5 человек с кнопками «Назад», «Вперед» и номерами страниц.
4. **Карточка студента:** кнопка «Подробнее» открывает детальную страницу (`/students/1/`) с кликабельными ссылками на факультет и группу, хлебными крошками (`breadcrumb`) и кнопкой возврата.
5. **Раздел «Группы» (`/groups/`):** в карточке группы (например, `ГР-101`) отображается полный состав зачисленных в неё студентов с переходом к каждому.
6. **Раздел «Преподаватели» и «Дисциплины»:** на странице преподавателя видны читаемые им курсы; на странице дисциплины — ссылка на профессора.

## 3. Запуск и демонстрация Проекта №2 — «Автопарк техники» (iammachines)

### Команды для запуска:
Откройте **второе отдельное окно командной строки** (не закрывая первое) и выполните:
```cmd
cd iammachines
py manage.py runserver 8001
```
В браузере откройте: **[http://127.0.0.1:8001/](http://127.0.0.1:8001/)** *(или [http://127.0.0.1:8001/machines/](http://127.0.0.1:8001/machines/))*

### Учетные данные для админки Автопарка:
* **Адрес админки:** [http://127.0.0.1:8001/admin/](http://127.0.0.1:8001/admin/)
* **Логин:** `admin` | **Пароль:** `admin`

### Что показывать преподавателю:
1. **Каталог техники:** адаптивная сетка карточек Bootstrap 5 (`card h-100 shadow-sm`), перестраивающаяся под ширину экрана.
2. **Счётчик:** сверху выведено общее число единиц техники (**«Всего единиц: 6»**).
3. **Цветовая индикация статусов (`badge`):**
   * Зелёный (`bg-success`) — «Исправна»
   * Жёлтый (`bg-warning`) — «В ремонте»
   * Серый (`bg-secondary`) — «На хранении»
   * Красный (`bg-danger`) — «Списана»
4. **Человекочитаемые значения:** вывод через `get_category_display` и `get_status_display` (технические коды choices скрыты).
5. **Детальная страница техники:** кнопка «Подробнее» открывает карточку с характеристиками (`dl row`) и описанием.
6. **Проверка 404:** при вводе несуществующего адреса (например, `/machines/999/`) сервер отдаёт стандартную 404 страницу.

## 4. Полезные команды для управления

* `py manage.py createsuperuser` — создать нового администратора.
* `py manage.py changepassword admin` — сменить пароль пользователю admin.
* `git pull` — получить свежие обновления из GitHub репозитория.
