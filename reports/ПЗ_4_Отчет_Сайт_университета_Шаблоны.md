# Отчет по практической работе №4
**Тема:** Сайт университета. Шаблоны и отображение данных  
**Проект:** hogwarts  
**Выполнил:** студент Храмов  
**Год:** 2026  

## 1. Цель работы
Изучение механизмов шаблонизации Django, построение базового шаблона base_generic.html с блоками block, использование механизма наследования extends, агрегация данных из базы данных с помощью ORM-запросов и передача контекста в шаблон через функцию render(), а также подключение статических стилей.

## 2. Задание к работе
1. Создать базовый шаблон base_generic.html со структурой HTML5 и блоками title, sidebar, content.
2. Подключить статический CSS-файл через тег {% load static %}.
3. В файле views.py в функции index подсчитать количество объектов каждой модели через метод count() и передать их в шаблон через словарь context.
4. Создать дочерний шаблон index.html, выводящий название университета и динамическую статистику объектов.
5. Организовать навигационное меню в сайдбаре со ссылками на разделы сайта.
6. Создать пустой шаблон-заглушку empty.html для будущих разделов и связать его в urls.py.

## 3. Ход выполнения работы
1. В `students/views.py` реализована функция `index(request)`, агрегирующая счетчики записей из базы данных.
2. Создан базовый шаблон `base_generic.html` со структурой сетки (3 колонки под меню, 9 под контент) и подключением файла `static/css/styles.css`.
3. Создан шаблон `index.html`, переопределяющий `{% block content %}` и выводящий полученные числовые показатели.

## 4. Результаты работы
Шаблоны успешно связаны. При изменении записей в БД счетчики обновляются автоматически.

## 5. Вывод
Освоено построение иерархии шаблонов в Django, передача динамических данных и организация структуры сайта.
