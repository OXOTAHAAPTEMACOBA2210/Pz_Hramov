# Отчет по практической работе №3
**Тема:** Сайт университета. Модели данных и административная панель  
**Проект:** hogwarts  
**Выполнил:** студент Храмов  
**Год:** 2026  

## 1. Цель работы
Изучение принципов построения реляционных баз данных с использованием Django ORM, проектирование структуры моделей предметной области университета, использование различных типов полей моделей и связей ForeignKey, реализация методов __str__() и get_absolute_url(), выполнение миграций и регистрация сущностей в интерфейсе Django Admin.

## 2. Задание к работе
1. Спроектировать структуру моделей университета: Факультет (Faculty), Группа (Group), Преподаватель (Teacher), Дисциплина (Discipline), Студент (Student).
2. Описать модели в файле students/models.py с необходимыми типами полей (CharField, TextField, DateField, EmailField, ForeignKey) и ограничениями.
3. Определить для каждого класса метод строкового представления __str__().
4. Реализовать метод get_absolute_url() для получения URL-адреса объекта.
5. Сгенерировать и применить миграции базы данных.
6. Зарегистрировать все модели в students/admin.py и наполнить таблицы данными.

## 3. Ход выполнения работы

### 3.1. Описание моделей (students/models.py)
Созданы классы `Faculty`, `Group`, `Teacher`, `Discipline`, `Student`. Все классы имеют метод `__str__()` (для студентов и преподавателей вывод в формате «Фамилия Имя»), метод `get_absolute_url()`, а также мета-параметры `verbose_name`, `verbose_name_plural` и `ordering`.

### 3.2. Регистрация в admin.py и миграции
Модели зарегистрированы в `students/admin.py`.
Выполнены команды:
```bash
py manage.py makemigrations
py manage.py migrate
```

## 4. Результаты работы
В базу данных SQLite внесены тестовые записи: 4 факультета, 4 учебные группы, 7 преподавателей, 7 дисциплин и 11 студентов.

## 5. Вывод
Освоены механизмы Django ORM: объявление моделей, миграции схемы БД, внешние ключи и интеграция с панелью администратора.
