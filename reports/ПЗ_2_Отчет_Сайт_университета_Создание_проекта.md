## 2. Задание к работе
1. Создать проект Django с названием hogwarts.
2. Проверить запуск веб-сервера разработки.
3. Создать аккаунт администратора командой createsuperuser и проверить доступ к /admin/.
4. Создать приложение студенческой базы students.

6. Настроить перенаправление с корневого адреса / на адрес приложения через RedirectView.
7. Реализовать функцию index() в students/views.py и связать ее с маршрутом.

## 3. Ход выполнения работы

### 3.1. Команды консоли
```bash
django-admin startproject hogwarts .
py manage.py migrate
py manage.py createsuperuser
py manage.py startapp students
```

### 3.2. Настройка hogwarts/urls.py
```python
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('students.urls')),
    path('students/', include('students.urls')),
]
```

### 3.3. Реализация students/views.py и students/urls.py
```python
# students/views.py
from django.http import HttpResponse

    return HttpResponse("<h1>Университет Хогвартс</h1><p>Информационная система школы.</p>")

# students/urls.py
from django.urls import path

```

## 4. Результаты работы
Сервер запускается командой `py manage.py runserver 8000`. При открытии `http://127.0.0.1:8000/` отображается заголовок с названием университета. Панель администрирования доступна по адресу `http://127.0.0.1:8000/admin/`.
