**Проект:** hogwarts  
**Выполнил:** студент Храмов  
**Год:** 2026  

## 1. Цель работы
Получение практических навыков оформления пользовательского интерфейса веб-приложения на Django с использованием CSS-фреймворка Bootstrap, применение компонентов сетки (Grid), навигационных списков (list-group), информационных панелей (panel), кнопок (btn), бейджей (badge), блоков оповещений (alert) и акцентных блоков (jumbotron).

## 2. Задание к работе
1. Настроить пропорции колонок сетки Bootstrap (col-sm-3 для навигации, col-sm-9 для контента).
2. Стилизовать меню навигации с использованием класса list-group.
3. Оформить заголовок главной страницы компонентом jumbotron.
4. Оформить каждый показатель статистики в отдельном блоке panel.
5. Разместить блоки статистики с использованием адаптивной сетки row и col-sm-6 / col-sm-4.
6. Добавить бейджи (badge) для отображения количества объектов в пунктах меню.
7. Добавить интерактивные кнопки перехода btn с различными вариантами оформления.
8. Разместить информационный блок оповещения alert.

## 3. Ход выполнения работы
В шаблоне `index.html` и базовом шаблоне `base_generic.html` применены классы Bootstrap 3. Элементы сгруппированы по строкам сетки `row`, пункты меню снабжены счетчиками `<span class="badge">`, шапка оформлена через `jumbotron`.

## 4. Результаты работы
Интерфейс адаптирован под различные разрешения экрана, блоки статистики наглядны и структурированы.

## 5. Вывод
Освоено практическое применение базовых компонентов Bootstrap для создания интерфейса веб-приложений.
